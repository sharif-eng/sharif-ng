## Introduction

Review Azure Service Health options for incidents, planned maintenance, and health advisories affecting Azure resources.

This project is being rebuilt from the **ICDFA Azure Fundamentals CCSE-F101 (AZ-900)** Skillable practical laboratory portfolio. The source portfolio records the activity as completed. The GitHub version is structured for a fresh independent rebuild with new screenshots.

## Objectives

- Rebuild the activity in Azure.
- Understand the service or control instead of only following steps.
- Apply the relevant cloud security, governance, monitoring, or operational concepts.
- Verify the final configuration.
- Capture clean technical evidence.
- Document challenges and lessons learned.

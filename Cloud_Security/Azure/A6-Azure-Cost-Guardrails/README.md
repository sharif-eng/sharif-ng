## Introduction

Create a budget and alert thresholds so Azure spending can be monitored and responsible users can be warned before planned limits are exceeded.

This project is being rebuilt from the **ICDFA Azure Fundamentals CCSE-F101 (AZ-900)** Skillable practical laboratory portfolio. The source portfolio records the assigned activity as completed. The GitHub version is structured so the lab can be repeated independently and documented with fresh screenshots.

## Objectives

- Rebuild the activity in Azure using a controlled practical environment.
- Understand the purpose of the Azure service or control rather than only following portal steps.
- Apply the relevant cloud security, governance, networking, identity, compute, monitoring, resilience, or cost-management concepts.
- Verify the resulting configuration.
- Capture screenshots that demonstrate the implementation.
- Document challenges and lessons learned.
- Connect the activity to practical Cloud Security Engineering.

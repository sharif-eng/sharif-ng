## 📌 Introduction

A controlled cybersecurity lab built with **Kali Linux** and **Metasploitable** in VirtualBox for practicing reconnaissance, enumeration, vulnerability assessment, controlled exploitation, and web application security testing.

## 🎯 Objectives

- Build an isolated cybersecurity testing environment
- Configure communication between attacker and target systems
- Perform reconnaissance and service enumeration
- Identify vulnerable services
- Practice controlled exploitation
- Test vulnerable web applications
- Map activities to the Cyber Kill Chain
- Document findings and observations

## 🛠️ Tools

**Kali Linux • Metasploitable • VirtualBox • Nmap • Metasploit • Burp Suite • Wireshark**

## 🧠 Skills Demonstrated

**Linux Administration • Reconnaissance • Network Enumeration • Vulnerability Assessment • Controlled Exploitation • Web Security Testing • Metasploit • Nmap • Traffic Analysis**

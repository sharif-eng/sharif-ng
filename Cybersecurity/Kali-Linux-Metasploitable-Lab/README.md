## Introduction

A controlled Kali Linux and Metasploitable lab for security testing.

## Environment / Architecture

Kali Linux and Metasploitable deployed in VirtualBox within an isolated lab network.

## Tools & Technologies

Kali Linux • Metasploitable • VirtualBox • Nmap • Metasploit • Burp Suite • Wireshark

## Challenges

The main challenge was keeping the configuration consistent and verifying each stage before moving to the next.

## Lessons Learned

The project reinforced the importance of structured implementation, verification, troubleshooting, and clear technical documentation.

## 📌 Introduction

A practical email security analysis exercise focused on examining email headers to understand message routing, sender information, authentication indicators, and other artifacts useful during phishing investigations.

## 🎯 Objectives

- Examine email header information
- Identify relevant sender and routing fields
- Analyze authentication-related indicators
- Trace message delivery information
- Extract useful indicators for investigation
- Document observations and findings

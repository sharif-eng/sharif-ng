## Introduction

A practical Active Directory IAM and Group Policy security lab.

## Environment / Architecture

Active Directory domain environment with users, groups, OUs, GPOs, password policy, and account lockout controls.

## Tools & Technologies

Active Directory • Windows Server • Windows 10 • Group Policy • Security Groups • Organizational Units • VirtualBox

## Challenges

The main challenge was keeping the configuration consistent and verifying each stage before moving to the next.

## Lessons Learned

The project reinforced the importance of structured implementation, verification, troubleshooting, and clear technical documentation.

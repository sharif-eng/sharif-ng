## 📌 Introduction

A practical **Identity and Access Management** lab using Active Directory to implement centralized identity, authentication, authorization, organizational structure, and Windows security policies.

## 🎯 Objectives

- Create users and security groups
- Organize identities using Organizational Units
- Implement role-based access concepts
- Configure Group Policy
- Apply password security controls
- Configure account lockout protection
- Verify policy enforcement on a Windows client

## 🔐 IAM Model

| Area | Implementation |
|---|---|
| Identity | Active Directory user accounts |
| Authentication | Domain authentication |
| Authorization | Security groups |
| Organization | Organizational Units |
| Policy | Group Policy Objects |
| Password Security | Password policy |
| Account Protection | Account lockout policy |
| Endpoint Control | Windows client policy verification |

## 🧠 Skills Demonstrated

**IAM • Active Directory • Access Control • Group Policy • User Administration • Security Groups • OUs • Authentication • Authorization • Windows Security**
